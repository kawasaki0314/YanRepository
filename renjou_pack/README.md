# タイトルシーンパッケージ (Renjou Title Scene)

このパッケージは、ゲームのタイトルシーンと関連スクリプトをまとめたものです。

## 📁 含まれているもの
- タイトルシーン (`TitleScene.unity`)
- タイトル画面の管理スクリプト (`TitleManager.cs`)
- ボタン用のUI素材など

## 🚀 導入方法（使い方）
1. Unityのプロジェクトを開く。
2. メニューバーの **Window > Package Manager** を開く。
3. 左上の **「＋」ボタン** から **「Add package from git URL...」** を選択する。
4. このリポジトリのURLを入力してインポートする。

## 🛠️ 注意点
- **TextMeshPro** パッケージに依存しているため、事前にプロジェクトへ導入しておいてください。
- シーンを追加した後は、`File > Build Settings` からビルド対象に設定してください。
